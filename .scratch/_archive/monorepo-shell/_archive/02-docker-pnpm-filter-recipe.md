## Answer

From Workspace root:

```bash
docker build -f apps/isee-china/Dockerfile -t isee-china:latest .
docker run -d -p 3001:3000 isee-china:latest
```

- **deps:** COPY root `package.json`, `pnpm-lock.yaml`, `pnpm-workspace.yaml`, and `apps/isee-china/package.json` → `pnpm install --frozen-lockfile`
- **builder:** `pnpm --filter isee-china build`
- **runner:** COPY nested `apps/isee-china/.next/standalone` → `/app/`, static → `./apps/isee-china/.next/static`, public → `./apps/isee-china/public`; `CMD ["node", "apps/isee-china/server.js"]` (requires App `outputFileTracingRoot` → Workspace root)
- **`.dockerignore`:** prefer `**/node_modules`, `**/.next`; add `.scratch`
